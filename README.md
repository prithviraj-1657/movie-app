# Movie Search App 🎬

## 📌 Description
This is a web application that allows users to search for movies and view details like title, year, and poster using a public API.

## 🌐 API Used
OMDB API - https://www.omdbapi.com/

## 🚀 Features (Planned)
- Search movies by name
- Display movie results
- Show movie details
- Responsive design

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API

## ▶️ How to Run
1. Download the project
2. Open index.html in browser
